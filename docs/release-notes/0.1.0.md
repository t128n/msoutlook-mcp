# msoutlook-mcp 0.1.0

An MCP server for **classic Outlook on Windows** through COM, with a polling
`new_mail` event. One executable, a local HTTP daemon, no app registration and no
Microsoft Graph permissions.

## Install

```sh
# mise (recommended)
mise use -g github:t128n/msoutlook-mcp@0.1.0
msoutlook-mcp setup

# or download msoutlook-mcp-x86_64-pc-windows-msvc.zip from the release assets,
# then run msoutlook-mcp.exe setup
```

`mise` picks the asset for the current platform. Windows is the supported
platform; the macOS and Linux binaries are development builds for `serve` and
the CLI, because COM is Windows-only.

Then:

```sh
msoutlook-mcp install   # per-user Task Scheduler logon task, no admin
msoutlook-mcp doctor
```

Start classic Outlook, sign in, and **minimize it; don't close it**. To keep it
out of the way, right-click the Outlook icon in the notification area and enable
**Hide When Minimized**.

## What is in this release

- Persistent PowerShell COM bridge with per-call timeout, HRESULT mapping and a
  fake bridge for tests.
- CLI and local daemon: `setup`, `doctor`, `install`, `uninstall`, `upgrade`,
  `serve`, `config`, `version`.
- Loopback Streamable HTTP MCP at `/mcp`, bearer token, Host/Origin checks, and
  `/health` with `connected` / `waiting_for_outlook` / `error`.
- Reconnect after Outlook closes, 2–60 s backoff, retryable tool errors.
- All 27 ported tools: read mail and calendar, guarded drafts/sends/replies,
  moves/flags, event drafts/invites, meeting responses, rules, contacts.
- `new_mail` event over poll and SSE push, persisted cursor, thin payload (no
  body).
- Task Scheduler logon tasks for the daemon and for Outlook minimized.
- Cross-platform release archives and `SHA256SUMS`.

## Safety

- Sending is **off** by default; `config set allow-send on` enables it without a
  restart.
- Every state-changing call creates a draft or needs `confirm=true`.
- Recipients are checked against the allowlist at creation and again at send
  time.
- Mail bodies, subjects and tokens are never logged.

## Not verified in 0.1.0

The implementation was built and tested on macOS against a fake COM bridge. A
real Windows machine with classic Outlook was not available, so these are
documented in `docs/windows-checklist.md` and are **not** claimed to work yet:

- Real COM calls, DASL acceptance, X.500 → SMTP, attachments, rules, contacts.
- Task Scheduler logon, restart, hidden launcher, `icacls`, locked-exe upgrade.
- A real Outlook close/restart or modal prompt.
- OpenCode waking on `new_mail` (depends on t128n/github-events-mcp#2).
- The manual smoke test against a real mailbox.

Use a test mailbox first. Do not enable sending until the checks pass.
