# msoutlook-mcp 0.2.2

Patch release: fixes PowerShell launch on Windows and GitHub release publishing.

```sh
mise use -g github:t128n/msoutlook-mcp@0.2.2
msoutlook-mcp setup
```

## What is new

- **PowerShell launch fix (#22, #23).** The daemon could not start PowerShell
  because the inline helper script (~45 KB) exceeded Windows' command-line length
  limit (~8 KB) when passed via `-EncodedCommand`. The script is now written to
  `%LOCALAPPDATA%\msoutlook-mcp\outlook-helper.ps1` and executed with
  `powershell -File`.
- **Release workflow idempotency.** The release action now uploads build assets
  to pre-existing GitHub releases instead of failing with an existing tag error.

## Compatibility notes

- A new file `outlook-helper.ps1` is created in `%LOCALAPPDATA%\msoutlook-mcp`
  on first use. The directory is the same location used for config, state, and logs.

The Windows verification caveat still applies: real COM/Outlook, Task Scheduler,
the hidden launcher, rules/contacts and OpenCode event wake-up remain unverified
and are listed in `docs/windows-checklist.md`. Use a test mailbox first; sending
is off by default.
