# msoutlook-mcp 0.1.1

Patch release: the default daemon port moves from **8787** (commonly used by
other tools) to **28471**. `setup` still checks the port and picks the next free
one, and the port remains configurable with `config set port`.

```sh
mise use -g github:t128n/msoutlook-mcp@0.1.1
msoutlook-mcp setup
```

Everything else is unchanged from 0.1.0. The Windows verification caveat still
applies: real COM/Outlook, Task Scheduler, the hidden launcher, rules/contacts,
and OpenCode event wake-up remain unverified and are listed in
`docs/windows-checklist.md`. Use a test mailbox first; sending is off by default.
