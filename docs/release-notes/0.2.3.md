# msoutlook-mcp 0.2.3

Patch release: support standard MCP protocol versions (2024-11-05 and 2024-10-07).

```sh
mise use -g github:t128n/msoutlook-mcp@0.2.3
msoutlook-mcp setup
```

## What is new

- **Standard MCP protocol negotiation (#25).** The server now supports standard
  protocol versions `2024-11-05` and `2024-10-07` in addition to experimental
  extensions. This allows MCP clients like OpenCode and Claude Desktop to
  initialize and discover tools cleanly without protocol mismatch errors.
- **Modern MCP wire result metadata.** `tools/list` responses now include
  `ttlMs` (0) and `cacheScope` ("private") required by modern MCP wire revisions.

The Windows verification caveat still applies: real COM/Outlook, Task Scheduler,
the hidden launcher, rules/contacts and OpenCode event wake-up remain unverified
and are listed in `docs/windows-checklist.md`. Use a test mailbox first; sending
is off by default.
